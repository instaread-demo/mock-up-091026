NVIDIA GeForce Game Ready 616.92 WHQL Driver Released

September 9, 2026 John Papadopoulos 8 Comments
Listen to audio version of this article
Sponsored by
0:00 / 2:23
Instaread

NVIDIA has just released a new driver for its graphics cards. According to the release notes, the NVIDIA GeForce Game Ready 616.92 WHQL driver is optimized for the upcoming Path Tracing Update of 007 First Light.

As NVIDIA notes, this driver also offers the best gaming experience in the latest new games and updates supporting DLSS and RTX technologies, including Active Matter, Aniimo, PUBG, and WARDOGS.

From what I can see, this driver does not pack any new bug fixes. Instead, it has those that were present in the recent Hotfix driver.

This means that the driver fixes some intermittent flicker issues that could occur in browsers when navigating to certain websites. It also fixes an issue where virtual displays could not be created after updating to driver 616.56. Finally, Remote Desktop Protocol (RDP) sessions will no longer display a black screen after updating to driver 616.56.

You can go ahead and download this new driver from this link. Below, you can also find its full changelog.

Stay tuned for more!

NVIDIA GeForce Game Ready 616.92 WHQL Driver Release Notes

Game Ready for 007 First Light, Active Matter, Aniimo & WARDOGS
Game Ready Driver which provides the best gaming experience for 007 First Light’s Path Tracing Update as well as the latest new games and updates supporting DLSS and RTX technologies including Active Matter, Aniimo, PUBG, and WARDOGS.

Fixed Gaming Bugs

  • N/A

Fixed General Bugs

  • Intermittent flicker may be observed in browsers when navigating to certain websites [6673430]
  • Fixed an issue where virtual displays could not be created after updating to driver 616.56 [6674464]
  • Remote Desktop Protocol (RDP) sessions may display a black screen after updating to driver 616.56 [6687328]
